Terminal Typing Tutor (TTT)

Learn and practice touch typing in the terminal.

Install:

Debian/Ubuntu:
`sudo apt update`
`sudo apt install g++`
`sudo apt install libncurses-dev`
`g++ typing.cc -lcurses -o typing`

To use:
`./typing lessons/lesson1.txt`
